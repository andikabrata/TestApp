# Test News App
aplikasi ini merupakan test dari gecidev, yang berisi tentang list news

## Fitur
- Home News
- Detail News
- Search News
- Save News

## Cara Menjalankan
- clone project dari url repostiry berikut di android studio: https://github.com/andikabrata/TestApp.git
- lalu change branch dengan memilih branch app/gencidev_test
- setelah itu jalankan projectnya
- Setelah berhasil run project maka aplikasi berhasil terinstall

NOTE:
jika terjadi token expired:
1. silahkan kunjungin website: https://newsapi.org/, lalu register terlebih dahulu untuk mendapatkan API KEY
2. lalu ganti API KEY di dalam project di file: HomeNewsRepositoryImpl -> ganti param apiKey menjadi apiKey yang anda dapat
3. lalu run project kembali untuk install aplikasi
